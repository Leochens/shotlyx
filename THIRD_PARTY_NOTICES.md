# Third-Party Notices

This index highlights distribution-critical provenance. Dependency manifests
remain the authoritative list of exact package versions.

## OpenCut

Shotlyx includes code derived from the OpenCut browser editor and runtime.

- License: MIT
- Preserved notice: [`licenses/OpenCut-MIT.txt`](licenses/OpenCut-MIT.txt)

## JavaScript and Rust dependencies

Dependencies are declared in:

- [`package.json`](package.json)
- [`apps/desktop/package.json`](apps/desktop/package.json)
- [`apps/renderer/package.json`](apps/renderer/package.json)
- [`Cargo.toml`](Cargo.toml) and the manifests under `rust/`

Binary distributors must include notices required by the exact dependency
versions included in the package. Electron packages already carry Electron and
Chromium license files generated by `electron-builder`.

## FFmpeg

FFmpeg and FFprobe are build inputs, not tracked repository files. Release
builders must record the exact version, source URL, SHA-256 checksums, target
architecture, and effective license for each bundle. If a build enables GPL
components, distributors must satisfy the corresponding GPL source and notice
requirements.

The packaging verifier and required manifest are documented in
[`resources/ffmpeg/README.md`](resources/ffmpeg/README.md).

## Assets and generated media

Tracked Shotlyx brand assets are subject to the trademark policy and are not a
general-purpose asset license. Imported stock media, user media, and provider
outputs remain subject to their source terms and are not relicensed by the
Shotlyx code license.

Do not add fonts, templates, footage, icons, model weights, generated samples,
or other third-party assets without recording verifiable provenance and all
required attribution.
